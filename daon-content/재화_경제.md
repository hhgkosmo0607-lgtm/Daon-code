# 재화·경제 (2026-09-29 기준)

앱에 있는 재화를 얻는 법, 쓰는 곳, 수치, 정한 이유를 이 문서 한 곳에 모은다.
수치를 바꾸면 **코드와 이 문서를 같이** 고친다. 코드 위치는 맨 아래 표에 있다.

---

## 한눈에 보기

```
레슨 풀기 ──▶ EXP ──▶ 레벨 (쌓이기만 한다)
         └─▶ 코인 ──▶ 코인 고양이 (80부터)
                          │ 많을수록 많이 캔다
앱 출석 ────▶ 고양이들이 채굴 ──▶ 채굴 게이지 ──▶ 프리즘
  (하루 1번)                                      ▲
현금 결제 (스토어 출시 후) ───────────────────────┘

프리즘 ──▶ 하루 빠진 스트릭 지키기 (사용자가 직접)
       └─▶ 프리즘 고양이 (무지개)
```

| 재화 | 얻는 법 | 쓰는 곳 | 화면 |
|---|---|---|---|
| **EXP** | 레슨 풀기 | 쓰지 않음. 레벨만 오른다 | 상단바 `LV3 ▓▓░░░` |
| **코인** | 레슨 풀기 | 코인 고양이 | 상단바 `12c` (누르면 상점) |
| **채굴 게이지** | 출석 (고양이 수만큼 자동) | 10이 차면 프리즘 1개 | 광산을 누르면 `채굴 ▓▓░░░ 4/10` |
| **프리즘** | 채굴, 현금 결제(출시 후) | 스트릭 지키기, 프리즘 고양이 | 상단바 도트 다이아몬드 + 개수 |

- **코인 = 공부해서 버는 재화, 프리즘 = 유료 재화**(듀오링고의 보석과 같은 자리).
  코인으로 프리즘을 살 수는 없다. 되면 유료 재화의 가치가 사라진다.
- 학습 잔디 달력(레벨 바를 누르면 나오는 초록 칸)은 **재화가 아니라 기록**이다.

---

## 1. EXP (레벨)

| 행동 | EXP |
|---|---|
| 레슨 처음 완료 | +10 |
| 전부 정답 | +5 |
| 하루 목표 달성 (그날 1번) | +20 |
| 이미 완료한 레슨 다시 풀기 | 0 (파밍 방지) |

- **100 EXP마다 레벨 1**, 하루 목표 기본값 20 EXP (`profiles.daily_goal`)
- 쓰는 곳이 없다. 공부한 만큼만 오르는 지표로 남긴다.

## 2. 코인 (공부 화폐)

| 행동 | 코인 |
|---|---|
| 레슨 처음 완료 | +5 |
| 전부 정답 | +3 |
| 하루 목표 달성 (그날 1번) | +10 |
| 이미 완료한 레슨 다시 풀기 | 0 |

- 레슨 하루 2~3개 기준 **하루 약 30코인**. 코인 가격은 이 수입을 기준으로 맞췄다.

## 3. 출석 채굴 → 프리즘

- **하루 한 번 앱(홈)에 들어오면** 고양이들이 캔 만큼 게이지가 찬다. 레슨을 안 풀어도 된다.
- 게이지 = **1 + 고양이 수** (1마리 2 · 4마리 5 · 8마리 9), **10이 차면 프리즘 1개**
- 고양이는 돌볼 필요 없이 늘 광산에서 일한다. 출석하면 받은 보상을 광산 패널로 보여준다.
- 날짜는 서버 시각의 한국 날짜로 정한다. 폰 시계를 바꿔도 더 받지 못한다.

| 고양이 | 출석 1번 게이지 | 프리즘 1개까지 (매일 출석) |
|---|---|---|
| 1마리 | 2 | 5일 |
| 2마리 | 3 | 4일 |
| 4마리 | 5 | 2일 |
| 8마리 | 9 | 거의 매일 |

## 4. 프리즘 (유료 재화)

- **보유 한도 없음**
- 얻는 법: 출석 채굴, 현금 결제(**스토어 출시 때** 붙인다 — 상점에 "프리즘 충전 (준비 중)" 자리만 있다)
- 쓰는 곳

| 쓰는 곳 | 프리즘 |
|---|---|
| 하루 빠진 스트릭 지키기 | 1 |
| 무지개 고양이 | 10 |

- 예전 이름은 "스트릭 프리즈"(최대 2개, 하루 빠지면 자동 사용). 2026-09-29에 프리즘으로 바꿨다.

## 5. 스트릭과 지키기

- 오늘이나 어제 공부했으면 이어진다. 오늘 풀면 +1.
- **딱 하루 빠지면 홈에 "스트릭 지킬래요?" 배너**가 뜬다.
  - [1개로 지키기] → 프리즘 1개를 쓰고 스트릭 유지. 오늘 풀면 +1로 이어진다.
  - [괜찮아요] → 그날은 다시 묻지 않는다. 지키지 않고 레슨을 풀면 1일부터 다시 시작.
  - **자동으로 쓰지 않는다.** 사용자가 직접 고른다.
- 이틀 이상 빠지면 지킬 수 없고 끊긴다.

## 6. 고양이

| | 고양이 | 가격 |
|---|---|---|
| 처음부터 | 치즈 | 무료 |
| 코인 고양이 6마리 | 하양·크림·회색·파랑·민트·분홍 | 80에서 한 마리마다 +40 (80·120·160·200·240·280, 합계 1,080) |
| 프리즘 고양이 | 무지개 | 프리즘 10 |

- 가진 고양이는 **전부 광산에 나오고**(최대 8마리), 한 마리마다 출석 채굴량 +1.

## 7. 게스트 규칙

- 게스트(익명)는 레슨의 **EXP·코인을 80%만** 받는다. 계정을 연결하면 깎인 20%를 돌려준다.
- 출석 채굴·고양이·프리즘은 게스트도 똑같다.

---

## 이렇게 정한 이유

**EXP와 코인을 나눈 이유 (듀오링고 방식)**
- XP는 레벨 하나에만 쓰여서 모아서 쓸 곳이 없었다. 쓰는 재화(코인)를 따로 두었다.

**프리즘을 유료 재화로 바꾼 이유 (2026-09-29)**
- 고양이가 캐는 크리스탈 다이아몬드 모양과 이름을 맞췄다.
- 한도 2개짜리 보험이던 프리즈는 고양이가 늘면 금방 가득 차서 채굴이 의미 없어졌다.
  한도를 없애고 쓸 곳(스트릭 지키기, 무지개 고양이)을 주었다.
- 스트릭 보호를 자동으로 쓰면 무지개 고양이를 사려고 모으던 프리즘이 모르게 줄어든다.
  → 빠진 다음 날 사용자에게 물어본다.

**먹이(잔디)를 없앤 이유 (2026-09-29)**
- 처음에는 출석 → 잔디 → 먹이 주기 → 채굴이었는데, 매일 먹이 버튼을 누르는 단계만 늘었다.
  출석만 하면 고양이가 알아서 캐게 바꿨다. 매일 들어오면 속도는 같다.

**수치를 이렇게 정한 이유**
- 고양이를 살수록 많이 캐야 사는 의미가 있다 → 게이지를 고양이 수에 비례하게.
- 첫 코인 고양이(80)는 사흘 치 코인으로 채굴이 1.5배가 된다. 뒤로 갈수록 비싸져서
  전부 모으면 한 달 남짓 걸리는 장기 목표가 된다.
- 무지개 고양이(프리즘 10)는 코인 고양이를 다 모은 뒤(게이지 +8/일) 2주쯤 모아야 한다.
  출시 후에는 현금으로 바로 살 수 있는 대표 상품이 된다.
- 스트릭 지키기(프리즘 1)는 고양이 1마리로도 5일 출석이면 한 번 쓸 수 있다.

**기각한 대안**
- *시간이 지나면 EXP가 차는 방치형* → 공부 안 해도 레벨이 오르면 레벨이 의미를 잃는다.
- *문제를 풀 때 비용 소모*, *하트(목숨)* → 핵심 행동인 공부에 비용을 붙이지 않는다.
- *코인으로 프리즘 사기* → 유료 재화의 가치가 사라진다.
- *"내 서버실" 방치형 코인 생산*, *먹이 주기* → 출석 자동 채굴로 대체했다.

## 원칙 (코드)

- 재화는 **전부 서버에서만** 바뀐다. 클라이언트가 직접 바꾸려 하면 DB 가드 트리거가 막는다.
- 규칙 파일(`*.ts`)은 앱과 서버가 **같은 파일**을 쓴다. 앱은 화면 표시·버튼 활성화에만 쓰고,
  최종 판단은 서버가 DB 값으로 다시 한다. 서버(Deno)도 불러오는 파일이라 다른 파일을 import하지 않는다.
- 구매·출석·스트릭 지키기는 DB 함수가 **행을 잠근 채 한 번에** 확인 → 차감 → 지급한다.

## 수치를 바꿀 때 고칠 곳

| 무엇 | 파일 | 상수·함수 |
|---|---|---|
| EXP, 코인, 레벨 | `features/lesson/domain/scoring.ts` | `XP_*`, `COIN_*`, `XP_PER_LEVEL`, `GUEST_XP_RATE` |
| 고양이 가격, 스트릭 지키기 비용 | `features/shop/domain/shopItems.ts` | `CAT_BASE_PRICE`, `CAT_PRICE_STEP`, `PRISM_CAT_PRICE`, `STREAK_REPAIR_PRISMS` |
| 출석 채굴 | `features/pet/domain/mining.ts` | `MINE_BASE`, `MINE_PER_CAT`, `MINE_PER_PRISM` |
| 어떤 고양이가 코인/프리즘인지 | `features/pet/domain/catSheet.ts` | `CAT_COLORS` |
| 스트릭 규칙 | `features/lesson/domain/streak.ts` | `updateStreak`, `streakStatus` |

- 이 파일들은 서버 함수도 쓰므로, 고친 뒤 **`npm run release`로 서버 함수까지 다시 배포**해야 적용된다.
- 수치만 바꾸는 건 DB 변경(`db push`)이 필요 없다. 규칙 자체를 바꿀 때만 마이그레이션이 필요하다.
