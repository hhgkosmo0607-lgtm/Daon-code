# 재화·경제 (2026-09-29 기준)

앱에 있는 재화 5가지를 얻는 법, 쓰는 곳, 수치, 정한 이유를 이 문서 한 곳에 모은다.
수치를 바꾸면 **코드와 이 문서를 같이** 고친다. 코드 위치는 맨 아래 표에 있다.

---

## 한눈에 보기

```
레슨 풀기 ──▶ EXP ──▶ 레벨 (쌓이기만 한다)
         └─▶ 코인 ──▶ 프리즘 구매 (50)
                  └─▶ 고양이 구매 (80부터)
                          │ 많을수록 많이 캔다
앱 출석 ────▶ 잔디 ──▶ 고양이 먹이 ──▶ 채굴 게이지 ──▶ 프리즘
  (하루 1번)                                      └─ 가득이면 코인 25

프리즘 ──▶ 하루 빠진 날 자동 사용 → 스트릭 유지
```

| 재화 | 얻는 법 | 쓰는 곳 | 화면 |
|---|---|---|---|
| **EXP** | 레슨 풀기 | 쓰지 않음. 레벨만 오른다 | 상단바 `LV3 ▓▓░░░` |
| **코인** | 레슨 풀기, 넘친 프리즘 | 프리즘·고양이 구매 | 상단바 `12c` (누르면 상점) |
| **잔디** | 하루 한 번 앱에 들어오기 | 고양이 먹이 | 광산을 누르면 먹이 패널 |
| **채굴 게이지** | 고양이에게 먹이 주기 | 10이 차면 프리즘 1개 | 먹이 패널 `▓▓░░░ 4/10` |
| **프리즘** | 코인으로 구매, 고양이 채굴 | 스트릭 보호 (자동) | 도트 다이아몬드 아이콘 |

학습 잔디 달력(레벨 바를 누르면 나오는 초록 칸)은 **재화가 아니라 기록**이다.
그날 번 XP를 보여줄 뿐, 먹이 잔디 개수와는 따로 움직인다.

---

## 1. EXP (레벨)

| 행동 | EXP |
|---|---|
| 레슨 처음 완료 | +10 |
| 전부 정답 | +5 |
| 하루 목표 달성 (그날 1번) | +20 |
| 이미 완료한 레슨 다시 풀기 | 0 (파밍 방지) |

- **100 EXP마다 레벨 1**
- 하루 목표 기본값은 20 EXP (`profiles.daily_goal`)
- 쓰는 곳이 없다. 공부한 만큼만 오르는 지표로 남긴다.

## 2. 코인 (화폐)

| 행동 | 코인 |
|---|---|
| 레슨 처음 완료 | +5 |
| 전부 정답 | +3 |
| 하루 목표 달성 (그날 1번) | +10 |
| 이미 완료한 레슨 다시 풀기 | 0 |
| 프리즘이 가득일 때 채굴로 넘친 프리즘 1개 | +25 |

- 레슨 하루 2~3개 기준 **하루 약 30코인**. 아래 모든 가격은 이 수입을 기준으로 맞췄다.

| 상품 | 가격 | 제한 |
|---|---|---|
| 스트릭 프리즘 | 50 | 최대 2개 보유 |
| 고양이 (7색) | 80에서 한 마리마다 +40 (8번째 320, 합계 1,400) | 색마다 1마리, 치즈는 처음부터 보유 |
| 테마 | 미정 (30~100 예정) | 기본 테마 1~2개는 무료로 남긴다 |

## 3. 잔디 (고양이 먹이)

- **하루 한 번 앱(홈)에 들어오면 +1.** 레슨을 풀지 않아도 준다.
- 날짜는 서버 시각의 한국 날짜로 정한다. 폰 시계를 바꿔도 더 받지 못한다.
- 먹이 1개를 주면 잔디 −1, 고양이가 **24시간 일한다** (채굴 모션).
  먹이를 안 주면 고양이는 계속 누워서 쉰다.

## 4. 채굴 게이지 → 프리즘

- 먹이 1개 = 게이지 **1 + 고양이 수** (1마리 2 · 4마리 5 · 8마리 9)
- 게이지 **10**이 차면 프리즘 1개

| 고양이 | 먹이 1개 게이지 | 프리즘 1개까지 (매일 출석 기준) |
|---|---|---|
| 1마리 | 2 | 5일 |
| 2마리 | 3 | 4일 |
| 4마리 | 5 | 2일 |
| 8마리 | 9 | 거의 매일 |

- 프리즘이 이미 2개면 넘친 만큼 **1개당 25코인**으로 바꿔 준다. 그래서 가득 차도 먹이를 줄 수 있다.

## 5. 스트릭 프리즘

- 예전 이름은 "스트릭 프리즈". 고양이가 캐는 크리스탈 다이아몬드 모양에 맞춰 **화면 이름만** 프리즘으로 바꿨다.
  코드·DB 이름은 그대로 `freeze`(`FREEZE_*`, `freeze_count`)다.

- 하루 빠진 날(마지막 학습 후 2일째) 자동으로 1개 써서 스트릭을 잇는다.
- 이틀 이상 빠지면 프리즘이 있어도 스트릭이 1로 돌아간다.
- 최대 2개 보유.
- 얻는 법 두 가지: 상점에서 50코인, 고양이 채굴.

## 6. 게스트 규칙

- 게스트(익명)는 레슨의 **EXP·코인을 80%만** 받는다.
- 계정을 연결하면 깎인 20%를 돌려준다 (EXP·코인 둘 다).
- 잔디·채굴·구매는 게스트도 똑같다.

---

## 이렇게 정한 이유

**EXP와 코인을 나눈 이유 (듀오링고 방식)**
- XP는 레벨 하나에만 쓰여서 모아서 쓸 곳이 없었다. 쓰는 재화(코인)를 따로 두었다.
- 기획서의 "프리즘 7일마다 1개 지급"은 코드에 지급하는 곳이 없어서 모든 사용자가 0개였다.
  → 코인 구매와 고양이 채굴로 얻게 바꿨다.

**기각한 대안**
- *시간이 지나면 EXP가 차는 방치형* → 공부 안 해도 레벨이 오르면 레벨이 의미를 잃는다.
- *프리즘을 화폐로도 쓰기* → "고양이 vs 스트릭 보험"에서 고민하게 된다. 한 재화가 두 역할을 하면 둘 다 제대로 안 된다.
- *문제를 풀 때 비용 소모*, *하트(목숨)* → 핵심 행동인 공부에 비용을 붙이지 않는다.
- *"내 서버실" 방치형 코인 생산* → 고양이 채굴(잔디 먹이)로 대체했다.

**채굴 수치를 이렇게 정한 이유**
- 고양이를 살수록 많이 캐야 사는 의미가 있다 → 게이지를 고양이 수에 비례하게.
- 첫 고양이(80)는 사흘 치 코인으로 채굴량이 1.5배가 돼서 금방 본전을 뽑는다.
  뒤로 갈수록 비싸져서 전부 모으는 데 한 달 반쯤 걸리는 장기 목표가 된다.
- 넘친 프리즘의 코인(25)은 8마리여도 하루 약 22코인이라 **레슨 수입보다 적다.**
  공부가 주 수입원으로 남는다.
- 넘친 프리즘 값(25)은 상점 가격(50)의 절반이다. 사고팔아서 코인을 불릴 수 없다.

## 원칙 (코드)

- 재화는 **전부 서버에서만** 바뀐다. 클라이언트가 직접 바꾸려 하면 DB 가드 트리거가 막는다.
- 규칙 파일(`*.ts`)은 앱과 서버가 **같은 파일**을 쓴다. 앱은 화면 표시·버튼 활성화에만 쓰고, 최종 판단은 서버가 DB 값으로 다시 한다.
- 구매·먹이·출석은 DB 함수가 **행을 잠근 채 한 번에** 확인 → 차감 → 지급한다. 동시에 눌러도 음수가 되지 않는다.

## 수치를 바꿀 때 고칠 곳

| 무엇 | 파일 | 상수 |
|---|---|---|
| EXP, 코인, 레벨 | `features/lesson/domain/scoring.ts` | `XP_*`, `COIN_*`, `XP_PER_LEVEL`, `GUEST_XP_RATE` |
| 프리즘 가격·최대, 고양이 가격 | `features/shop/domain/shopItems.ts` | `FREEZE_PRICE`, `FREEZE_MAX`, `CAT_BASE_PRICE`, `CAT_PRICE_STEP` |
| 잔디, 채굴, 넘침 코인, 일하는 시간 | `features/pet/domain/mining.ts` | `GRASS_PER_ATTENDANCE`, `MINE_*`, `FREEZE_OVERFLOW_COINS`, `WORK_HOURS_PER_GRASS` |
| 프리즘 자동 사용 | `features/lesson/domain/streak.ts` | `updateStreak` |

- 이 파일들은 서버 함수도 쓰므로, 고친 뒤 **`npm run release`로 서버 함수까지 다시 배포**해야 적용된다.
- 수치만 바꾸는 건 DB 변경(`db push`)이 필요 없다. 규칙 자체(예: 새 재화)를 바꿀 때만 마이그레이션이 필요하다.
