# 구글/카카오 로그인 설정 가이드

앱 쪽 코드(`features/auth/authActions.ts`, `features/auth/screens/AuthScreen.tsx`)는
이미 다 구현돼있습니다. 아래 세 가지만 콘솔에서 직접 하면 실제로 로그인까지 됩니다.

이 프로젝트의 Supabase 콜백 주소 (Google/Kakao 양쪽에 똑같이 등록):
```
https://fjtjoqdsrndnemhiqbmc.supabase.co/auth/v1/callback
```

---

## 1. Google Cloud Console (console.cloud.google.com)

1. 프로젝트 생성 (또는 기존 프로젝트 선택)
2. 좌측 메뉴 "API 및 서비스" → "OAuth 동의 화면"
   - User Type: **외부** 선택
   - 앱 이름 / 사용자 지원 이메일만 입력하고 저장 — 아직 심사(게시) 필요 없음, 테스트 단계로 충분
3. "API 및 서비스" → "사용자 인증 정보" → "사용자 인증 정보 만들기" → "OAuth 클라이언트 ID"
4. **애플리케이션 유형은 반드시 "웹 애플리케이션"** 선택
   - Android/iOS 타입 아님 — Supabase가 서버에서 대신 처리하는 방식이라 웹 타입이 맞습니다
5. "승인된 리디렉션 URI"에 위 콜백 주소를 정확히 입력
6. 생성 완료 시 나오는 **클라이언트 ID**와 **클라이언트 보안 비밀(secret)** 둘 다 복사해두기

---

## 2. Kakao Developers (developers.kakao.com)

1. "내 애플리케이션" → "애플리케이션 추가하기"
2. 앱 생성 후 "카카오 로그인" 메뉴에서 활성화 ON
3. "Redirect URI"에 위 콜백 주소 등록
4. "앱 키" 메뉴에서 **REST API 키** 복사 (Supabase의 Client ID 칸에 넣을 값)
5. "보안" 메뉴에서 **Client Secret** 생성 후 활성화, 복사
6. (선택) "카카오 로그인 → 동의항목"에서 닉네임/이메일 등 원하는 항목 설정
   - 이메일 동의항목은 "비즈 앱" 전환이 필요할 수 있음

---

## 3. Supabase 대시보드

프로젝트: `daon-code` (fjtjoqdsrndnemhiqbmc)

1. Authentication → Providers → **Google** 켜기, 위에서 받은 Client ID/Secret 입력 후 저장
2. Authentication → Providers → **Kakao** 켜기, REST API 키를 Client ID 칸에, Client Secret 입력 후 저장
3. Authentication → URL Configuration → Redirect URLs에 앱 딥링크 추가:
   ```
   daoncode://*
   ```

---

## 확인 방법

위 세 가지가 끝나면 앱의 로그인 화면에서 "구글로 계속하기" / "카카오로 계속하기" 버튼을 눌러
실제로 로그인이 완료되는지 테스트하면 됩니다.

**참고**: 게스트(익명 계정) 상태에서는 이 두 버튼이 화면에 아예 안 보입니다. `signInWithOAuth`는
"새 로그인"이라 지금 쓰고 있는 익명 세션과 무관한 새 계정을 만들어버려서, 게스트로 쌓은
진도가 끊기기 때문입니다. 게스트 상태에서 구글/카카오로 이어가려면 `linkIdentity`를 따로
구현해야 하는데, RN에서는 동작이 더 까다로워서 아직 붙이지 않았습니다 — 게스트는 지금처럼
이메일 연결(`upgradeGuestToEmail`)만 가능합니다.

## 막히면

- Google 쪽: OAuth 동의 화면이 "게시됨" 상태가 아니어도 테스트 사용자 등록 없이 로그인 자체는
  됩니다 (구글 계정으로 로그인하면 "확인되지 않은 앱" 경고만 뜨고 진행 가능).
- Kakao 쪽: Client Secret을 활성화하지 않으면 Supabase가 요구하는 필드가 비어서 저장이 안 될
  수 있습니다.
- 그래도 안 되면 에러 메시지를 캡처해서 물어보세요.
