### SQLD 트랙 — 완료
- 정보처리기사보다 먼저 착수 (시험 범위가 좁고 공개돼 있어서)
- 참고 자료: yunamom.tistory.com (SQLD 기출복원/이론 블로그) — 기출복원 글은 인터랙티브
  퀴즈 위젯이라 텍스트 추출 불가, 이론 글(PIVOT/UNPIVOT 등)로 출제 스타일만 참고함.
  오라클 문법 세부사항(서브쿼리 별칭, 컬럼 인용 규칙 등)까지 파고드는 문제가 있어서,
  SQL 세부 챕터는 실제 기출/수험서 없이 임의로 쓰지 않기로 함
- 트랙 구조는 공식 커리큘럼 그대로 세팅 (`content/tracks.json`에 `sqld` 추가):
  - 과목 I: 1장 데이터 모델링의 이해(엔터티/속성/관계/식별자), 2장 데이터 모델과 SQL(정규화/조인/NULL/트랜잭션)
  - 과목 II: 1장 SQL 기본(SELECT/함수/WHERE/GROUP BY/JOIN/서브쿼리), 2장 SQL 활용(집합연산자/계층형질의/PIVOT/윈도우함수/정규표현식), 3장 관리구문(DDL/DML/TCL/DCL)
  - 총 5스테이지 22레슨 뼈대(`content/lessons.json`)를 다 만들어뒀고, 문제 콘텐츠는 아직
    파일럿 1개(`sqld-1-1`)만 있음 — 나머지는 "준비중"으로 뜸
- **전체 22레슨(84문제) 작성 완료** — 사용자가 알려준 SQLD 참고 블로그(yunamom.tistory.com)의
  "SQLD 이론" 카테고리(과목II 1~3장 정리글, PIVOT/UNPIVOT, 정규표현식, 부정비교연산자 글)를
  근거로 오라클 문법 세부사항(CONNECT BY PRIOR 방향, MINUS는 Oracle 전용, NVL vs ISNULL,
  DELETE/TRUNCATE 롤백 가능 여부 등)까지 확인 후 원문을 베끼지 않고 원본 문제로 작성함.
  기출복원 글 자체는 인터랙티브 위젯이라 텍스트 추출이 안 돼서 실제 기출 그대로 옮긴 건 없음
- 구조 검증 스크립트로 전체 84문제의 id 중복, answer 인덱스 범위, order 타입 정답 배열이
  options의 순열인지까지 확인함
- **사용자 검토 필요** — 특히 Oracle 문법 세부사항(3~5단계) 문제들은 실제 오라클 환경이나
  최신 기출과 대조해서 확인해주면 좋음. 틀린 부분 있으면 바로 수정
